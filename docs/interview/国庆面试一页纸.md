## 必背公式 / 链

**MetaNode `_settle`：** `credit = paper×fundingRate + reducedCredit` → 更新 paper/credit → `reducedCredit = credit − paper×fundingRate`  
**安全：** `netValue ≥ MM`（`MM = Σ|paper×mark|×阈值`）｜**成交：** EIP-712 → Go 撮合 → `trade()` → Dealer 验签 → `_settle`  
**Kinza HF：** `(总抵押×avgLiquidationThreshold) / 总债务`｜**余额：** `scaled × liquidityIndex / 1e27`
